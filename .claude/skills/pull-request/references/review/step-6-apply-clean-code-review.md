# Step 6 — Apply Clean Code Review

Use the **[clean-code](../../../../guides/CLEAN_CODE/ENTRY_POINT.md)** guide on the diff. Apply all its principles (SOLID, DRY, KISS, Separation of Concerns, Atomic Design). Then run the **[Code Review Checklist](./code-review-checklist.md)**.

For each problem, write down:

- **File and line range** (from the diff)
- **Principle violated**
- **Explanation** (one sentence)
- **Suggested fix**
